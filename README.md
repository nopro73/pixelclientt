# Eaglercraft Offline Version List



This is a list of all offline versions of the Eaglercraft client. Offline means that they can run as standalone HTML files without any interference from a site! If you are looking for a site to play on however, these are all hosted on https://eaglercrafthub.com and you can download them again there too.



# Adding To This List



If you have your own version you want to add, just fork the repository and add it through the use of a Pull Request. We accept any and all versions!
